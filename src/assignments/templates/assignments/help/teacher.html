Creating an assignment
  1. Open the Assignments dashboard and choose Create Assignment.
  2. Set the title, description, class, subject, and due date.
  3. Attach any reference files and publish.
Reviewing submissions

Open an assignment to see the list of student submissions, their status, and submission timestamps. Use the grading tools to score and return feedback.
